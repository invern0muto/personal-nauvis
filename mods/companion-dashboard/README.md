# Personal Nauvis Companion Dashboard

Low-impact live telemetry for Factorio 2.0 servers. It retains the `fdash`
remote interface and `script-output/fdash/` format and adds a
`personal_worlds` dataset when Personal Nauvis is installed.

Includes server/player status, surfaces, power, production, machines,
logistics, trains, circuits, resources, fluids, threats, research, platforms
and Personal Nauvis ownership/mode metadata.

Derived from **fdash-exporter** by boehla/CryptoJunky11 under the MIT License.
