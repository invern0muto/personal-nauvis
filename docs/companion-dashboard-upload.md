# Companion Dashboard — Mod Portal upload

## Title

Personal Nauvis Companion Dashboard

## Summary

Low-impact server telemetry for Personal Nauvis and multiplayer Factorio 2.0 dashboards.

## Description

Companion Dashboard exports live Factorio server telemetry without blocking the simulation. Work is distributed across ticks with configurable budgets, making it suitable for persistent multiplayer servers.

It exposes server and player status, surfaces, power networks, machines, production, logistics, trains, circuits, research, mining resources, fluids, threats and Space Age platforms. When Personal Nauvis is installed, it also exports each personal world, its owner, online/protection state and selected co-op or PvP mode.

Data is available through the `fdash` remote interface and `script-output/fdash/`, preserving compatibility with existing fdash dashboard readers.

Personal Nauvis is optional. On ordinary Factorio saves the exporter remains fully functional.

Public dashboard and test server: https://pn.vortexbrain.com
